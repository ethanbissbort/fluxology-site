# Site Audit — August 2, 2026

Repo-wide bug hunt, feature-oversight crawl, live web-test suite, and
performance review, followed by remediation. Every finding below was
independently re-verified against the code and the running site before
being accepted (adversarial verification: a second reviewer attempted to
refute each claim with its own measurements), and every fix was
re-tested by two independent regression suites before merge.

## Method

- 13 parallel auditors: 5 bug-hunt dimensions (Svelte components, Astro
  templates, CSS, PWA/service worker, deploy config), 2 feature-oversight
  crawls (docs vs implementation, data/content completeness),
  accessibility, static performance analysis, and 4 live Playwright
  suites (crawl/console health, interactive components, responsive
  layout, SEO/PWA runtime).
- 89 raw findings → 65 confirmed after adversarial verification,
  2 refuted, 22 informational notes.
- Remediation in 3 waves on disjoint file sets, each fix verified
  against a private build before landing.
- Final regression: 28/28 functional checks and 8/8 platform suites
  pass with zero console errors, zero failed requests, zero horizontal
  overflow at 375/768/1440, and zero broken images.

## Fixed — high severity

| Problem | Resolution |
| --- | --- |
| In-page anchor links landed ~5,700 px short (smooth scroll against `content-visibility` size estimates that undershot real section heights) | Removed the intrinsic-size containment from page sections; anchors now land within 72 px of target on every route |
| Collapsed-menu links overlapped: tapping a link activated the item below it | `.nav-link` made `display:block`; tap targets ≥44 px, verified hit-testing per link |
| `body { overflow-x: hidden }` silently disabled the sticky section nav on all DBA pages | `overflow-x: clip` on html/body; local nav pins at 68 px |
| Offline rendered a completely unstyled page; unknown offline routes impersonated the home page with HTTP 200 | Service worker v2.4.0: primes runtime caches from the shell's real subresources, network-first navigations, cache-first hashed assets, stale-while-revalidate others, branded `offline.html` served as 503 |
| DBA comparison tables unreachable on mobile (clipped, no scroll) | Container `min-width:0` so the wrappers' `overflow-x:auto` engages |
| CTA/text contrast failures across all four themes (down to 1.70:1) | Dark-ink CTAs on bright brand surfaces, deepened corporate CTA, lightened accents, darkened natural gradients; 49/49 live worst-pixel checks ≥ WCAG AA |
| 4.87 MB of raw single-variant images served from `public/` | Migrated to `astro:assets` (480/800/1200 ladders, intrinsic dimensions, eager LCP + lazy below fold); DBA-page transfer −40…−68 %, hero LCP payloads halved; postbuild prune removes 4.3 MB of unreferenced originals from each build |
| `claude.md` documented the obsolete single-page architecture | All seven docs rewritten/synced against the current codebase |

## Fixed — medium/low (selection)

- Contact form no longer ships `novalidate` in server HTML: native
  validation guards pre-hydration/no-JS submits; the status live region
  is permanently in the DOM so screen readers hear results.
- Collapsed nav: focus trap + focus restore, correct dropdown anchoring,
  no font-size jump at the 1023/1024 boundary.
- Reduced motion: `animation-delay` zeroed (hero no longer invisible for
  up to 0.8 s); CursorEffects and ParticleSystem now react to media
  query and viewport changes at runtime and tear down cleanly.
- Service worker origin check compares real origins (the old prefix
  check also matched `fluxology.ca.evil.example`); precache fetches
  bypass HTTP cache; manifest/theme-color now match the real background.
- SEO: generated sitemap (`@astrojs/sitemap`) replaces the drifting
  hand-maintained file; 404 is noindexed with no phantom canonical and
  now has site navigation; og:image ships dimensions/alt; built-in
  prefetch enabled (viewport strategy); theme-aware font preloads per
  DBA page; never-loaded font references remapped.
- Static-host and Apache cache policies were aligned (immutable hashed
  assets, 7-day images, no-cache HTML/SW); Apache Expires no longer
  contradicts Cache-Control; dead deployment config was removed.
- Dead CSS removed (parallax remnants, stale `will-change`, wrong
  containment selector); all five particle variants hidden on mobile;
  empty particle containers removed from Hero/About.

## Refuted in verification (not real issues)

- "Accent small text borderline on industrial/gold gradients" — passed
  when measured against the actual rendered pixels.
- "Micro-chunk JS files cost more than they carry" — the chunks are
  preloaded and coalesced; no measurable cost.

## Known gaps — deliberate, needs an owner decision

1. **Privacy Policy / Terms pages do not exist.** `Footer.astro` carries
   the only TODO in the tree, with commented-out `/privacy` and `/terms`
   links, while the contact form collects PII. Writing legal pages is a
   business/legal decision — not auto-generated here.
2. **Three service cards render placeholder tiles** (Fence & Gate Work,
   CAD & Model Cleanup, Fit-up & Reverse Modelling) — the only 3 of 16
   services without an `image` field. Needs photography/renders.
3. **Two greenhouse cards pair copy with mismatched imagery** (Season
   Extension shows coffee cultivation; Propagation & Starts shows
   cocoa) — stale exotic-crop framing; a content decision.
4. **Typography consolidation (optional).** All nine loaded font
   families are genuinely used (per-theme heading/body/accent sets) and
   browsers fetch them per-use, so this is a design choice, not waste;
   merging themes onto fewer families would still shrink worst-case
   font bytes.
5. **Minor service-worker follow-up:** the install-time primer caches
   `src` fallbacks but not srcset variants, so a handful of small icon
   variants miss offline on the home page (page still renders fully
   styled offline).

## Performance snapshot (after)

- DBA page transfer at 375 px: fabrication 170 KB, 3d-lab 323 KB,
  orchard 473 KB, greenhouse 507 KB (previously 0.5–1.8 MB).
- Exactly one eager `fetchpriority=high` LCP image per route; all other
  imagery lazy with intrinsic dimensions (no CLS).
- Shipped service worker minified 12.1 KB → 4.0 KB (1.7 KB gzip).
- Cross-page navigations prefetched on viewport; fonts preloaded
  per-theme; hashed assets use immutable caching at the serving layers.
