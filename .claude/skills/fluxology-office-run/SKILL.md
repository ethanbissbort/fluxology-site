# Fluxology Office Run

Ported verbatim from the ChatGPT automation "Fluxology Inc. Office Search"
(snapshot 2026-08-17); the OPERATIONS section maps it onto the Fluxology
tool stack. The spec below is normative.

## OPERATIONS (tool mapping)

- **Research** — primarily WebSearch/WebFetch across provider marketing
  sites, location pages, pricing pages, and listing sources. For JS-heavy
  pages that render poorly over plain fetch, and for Kijiji office-space
  listings, use the Browser Bridge connector (`browser.navigate` +
  `browser.snapshot`/`browser.extract`; the kijiji.ca.v1 profile extracts
  any Kijiji ad page, office rentals included).
- **Dashboard writes** — `dashboard.feed` `{dashboard:"office", mode:"ids"}`
  to diff, then `dashboard.upsert` `{dashboard:"office", listings:[...]}`.
  Match `public/office-scout/data/schema.json` (Office Scout v2.5)
  conventions; keep provider-level records distinct from location/offer
  records where the schema permits, and never overwrite historical quotes —
  append price observations so advertised-to-offer behavior can be learned.
- **Fallback write path** — update `public/office-scout/data/listings.json`
  (and `managed-providers.json` for provider profiles) on `main` of
  `ethanbissbort/fluxology-site` via the GitHub API, merging by stable id
  and preserving every unrelated record; skip the commit when nothing
  materially changed.
- **Email** — NEVER send email from a scheduled run. Outreach output is
  (1) OUTREACH QUEUE records upserted to the dashboard and (2) fully drafted
  message text in the completion report. Actual sending goes through the
  mail-mcp approval workflow documented in `docs/EMAIL-WORKFLOW.md`
  (human CLI approval per message, transport via mail.fluxology.ca).
- **Degraded runs** — if a needed capability is missing (bridge not
  attached, a provider site blocks fetches), say exactly what was missing
  and how coverage was affected; never fabricate coverage.

## TASK SPECIFICATION (normative, ported verbatim)

Run a complete fresh office-market search for Fluxology Inc. in Toronto, Mississauga, and the wider GTA, and ALWAYS produce TWO SEPARATE DELIVERABLES: (A) NON-MANAGED PRIVATE OFFICES and (B) MANAGED-OFFICE PROVIDERS / PRIVATE OFFICES. Do not merge the categories.

GENERAL REQUIREMENTS: When referring to the legal company name, use exactly "Fluxology Inc." — no comma, with the period after Inc. Accept locations up to roughly a 20-minute walk from the final TTC, GO, MiWay, YRT, Brampton Transit, Durham Region Transit, or Burlington Transit stop because the user will use an electric skateboard; note whether the final route appears skateboard-practical. Prefer genuine 24/7/365 access AND genuine 24/7 climate control/air conditioning; treat access without usable after-hours cooling as materially inferior and explicitly distinguish the two. Prefer individually lockable, fully closeable PRIVATE OFFICES, secure overnight equipment storage, internet, cleaning, mail/package handling, short/flexible commitments, and clear all-in pricing. A desk, hot desk, dedicated desk, coworking membership, open-plan workstation, booth, pod, or non-enclosed workspace DOES NOT QUALIFY as a private office and must never be presented as one. Treat CAD $850/month as the target budget, not an automatic rejection line for managed offices when included services/network value materially improve the economics. For non-managed offices, continue to treat CAD $850/month as the practical hard all-in ceiling unless an exceptional reason is identified.

DELIVERABLE A — NON-MANAGED PRIVATE OFFICES: Search private rooms within existing professional suites, office shares, commercial subleases, upper-floor offices, incubator/institutional offices, independent non-network business centres, and unusually inexpensive conventional offices. Exclude major managed-office networks from this category. WITHIN THE NON-MANAGED CATEGORY, strongly prefer higher square footage as compensation for weaker amenities. Rank usable private square footage as a major value factor: when two conventional offices have similar all-in cost and operating certainty, materially larger enclosed space should win even if cosmetic quality is lower. Report $/usable-private-sq-ft/month whenever reliable square footage exists. Surface especially attractive large-space bargains even if their amenity package is sparse, provided mandatory costs remain acceptable. For each surfaced listing include address/unit, asking rent, estimated all-in monthly cash cost, HST/TMI/utilities/internet/cleaning/mandatory-fee status, usable private square footage, $/usable-private-sq-ft/month where calculable, furnished status, lease/sublease/license type, lockable-door status, access hours, 24/7 access status, 24/7 HVAC/AC status separately, overnight equipment policy if known, mail/signage/package rights, amenities, transit connection, final walking distance, skateboard practicality, term, listing status, date/time verified, and exact verified source URL. CRITICAL LINK RULE: surface only exact live/active listing URLs verified during this run. No generic search pages, stale caches, wrong properties, homepages, or unverifiable redirects. If unresolved details materially affect value, classify the listing as CLARIFICATION REQUIRED and list the exact questions to ask rather than silently assuming.

DELIVERABLE B — MANAGED-OFFICE PROVIDERS / PRIVATE OFFICES: Put EXTRA SEARCH EFFORT here. Search provider marketing sites, location pages, private-office pages, membership/network-access pages, amenity pages, FAQ/terms pages, pricing/quote pages, current promotions, and any directly available inventory. Research both COMPANY LEVEL and SPECIFIC GTA LOCATION LEVEL. Maintain a managed-office watchlist and directly research at minimum: IWG brands (Regus, Spaces, HQ, Signature as applicable), Industrious, WeWork where currently operating/relevant, Intelligent Office, Venture X, Telsec Business Centres, Workhaus, iQ Offices, Workplace One, Staples Studio / coworking offerings if active/relevant, and other serious Toronto/GTA managed-office operators discovered during research. Add worthwhile providers to the watchlist rather than waiting for explicit user instruction. Never confuse per-desk, per-person, coworking, dedicated-desk, or membership pricing with a private-office price. A surfaced price may be labelled PRIVATE OFFICE only when first-party or otherwise reliable evidence confirms that the quoted amount buys an enclosed, closeable private office. Otherwise label it PER DESK/PER PERSON/UNKNOWN and do not use it as the private-office sticker price in scoring.

For each managed-office provider build/update a provider profile covering: GTA footprint; useful Canadian/international network footprint; reciprocal coworking/lounge rights and exact limits if known; private-office furnishing; whether the advertised product is a fully enclosed closeable private office; true 24/7 access policy; true 24/7 HVAC/AC policy as a separate field; cleaning; internet/Ethernet; reception; mail/package handling; meeting-room/phone-booth access and credits; guest policy; business-address rights; F&B quality and availability (coffee/espresso/tea/cold drinks/snacks/beer or other food where applicable, replenishment, hours, whether included); security/access control; ability to leave computer/electronics equipment overnight; contract/licence flexibility; setup/admin/deposit/retainer/restoration fees; auto-renewal/escalation rules; cancellation/notice; current incentives; and reputation for extra fees where supportable. Prefer first-party provider sources for current inclusions and terms; use reliable third-party sources only for context that providers do not publish.

MANAGED-OFFICE VALUE MODEL: Score each provider/location/offer separately using a 100-point Managed Office Value Score: all-in economics 22; private-office quality 16; access & operational certainty 13; F&B 12; network privileges 10; internet & technology 8; meeting/collaboration 6; mail/logistics 5; location/access 5; contract flexibility 3. In private-office quality and access certainty, penalize any ambiguity that the space may be open-plan or that 24/7 access lacks 24/7 AC. Calculate four different figures wherever possible: (1) confirmed private-office sticker/advertised monthly price, (2) contracted cash price including mandatory recurring charges, (3) first-year effective monthly price after free months/credits/waived fees/upfront-prepayment discounts, and (4) Fluxology Effective Monthly Cost after conservative credits for genuinely useful bundled services/avoided costs. Do not mechanically credit optional benefits at face value; distinguish actual avoided spend from option value. Give unusually good F&B real weight because the user is a heavy coffee/snack user. Distinguish a basic Keurig/tea station from a genuinely stocked café/snack program.

TERM-PREPAYMENT / NEGOTIATION: Discounts for paying a committed term upfront are specifically desirable. During initial outreach or an appropriate follow-up, ask whether the provider/landlord offers a discount, free months, reduced rate, waived fees, or other consideration for prepaying 6, 12, or 18 months (or another sensible term) in advance. Do not volunteer to prepay before verifying the premises and complete economics, but make prepayment a standing negotiation lever. Record quoted prepay terms, nominal discount, effective monthly savings, refund/cancellation implications, and whether the discount survives renewal. Include prepayment economics in first-year effective price.

MANAGED-OFFICE OUTREACH READINESS: For any provider/location that appears promising but lacks price or important details, include an OUTREACH QUEUE record with: provider, target location(s), sales/contact channel if publicly available, exact unresolved questions, requested quote structure, and negotiation targets. Frame Fluxology Inc. as a small corporate buyer comparing managed-office vendors, not as a generic consumer asking for the cheapest room. Target approximately CAD $750–850/month depending on included services/network value, but do not present $850 as an absolute ceiling in outreach. Request the best available ONE-PERSON, FULLY ENCLOSED, CLOSEABLE PRIVATE-OFFICE offers; explicitly reject coworking-only and dedicated-desk products. Ask separately about true 24/7 access and true 24/7 AC/HVAC. Invite alternatives such as discounted monthly rate, 6/12/18-month prepayment discounts, free months, waived setup/admin fees, meeting-room credits, upgraded office size, enhanced network access, parking discounts, mail services, or more flexible termination. Any actual email send must require explicit per-message human approval through the approved Fluxology email/MCP workflow; never autonomously send.

SEARCH COVERAGE / AUDIT: Every run must be auditable. Report exact numbers actually inspected: non-managed search-result/listing records; exact listing pages individually opened/validated; managed-office provider/company pages inspected; managed-office GTA location/inventory/offer pages inspected; number of providers deeply researched; number of specific managed locations evaluated; number reaching detailed scoring; number surfaced; number placed in outreach queue; and duplicates/stale/dead pages or other exclusions when practically trackable. If a search engine, provider site, API, or UI caps/truncates results, state the limitation and exact count processed. Do not claim comprehensive coverage beyond what was actually processed.

DASHBOARD: Normalize meaningful office findings, managed-provider profiles, managed-location profiles, quote/outreach state, and watchlist changes into the Fluxology office dashboard if an authenticated dashboard or repository integration is available. Preserve existing unrelated data. Managed-office providers must have distinct provider-level records plus location/offer records where the dashboard schema permits. Watchlist membership should persist across runs. Do not overwrite historical quotes; retain advertised price, quoted price, date, fees, incentives, upfront-prepayment offers, and material terms so advertised-to-offer discount behavior can be learned over time.

NO-SILENCE RULE: Every scheduled run must return a user-visible completion report with both deliverables and the coverage audit even if no worthwhile new office is found.
